# NiceTool 紧凑视觉基线

仅在新增或调整 UI 时加载。只改业务逻辑时保留现有布局。

## 页面与层级

- 用一句话确定用户的输入、核心动作和结果，选择数据、动作或结论作为唯一焦点。
- 复用平台页面壳，不重复顶栏、返回入口和工具名，不添加整页 `max-w-*`、`mx-auto` 或 `px-*`。
- 根布局使用 `ui.column().classes("w-full gap-3")`；复杂详情可用 `gap-4`。
- 仅在需要补充任务上下文时添加 `text-lg font-semibold app-text-primary` 页头。
- 使用 `ui.card().classes("w-full").props("flat")`；不重复添加边框、阴影。
- 按语义分组，避免重复的“查询条件”“功能区域”标题和无用指标卡。

## 控件与颜色

- 输入、选择使用 `outlined dense color=primary`；表格使用 `flat dense`。
- 普通按钮默认文字且 `dense`；仅表格行多操作可使用带 tooltip 的图标按钮。
- 平台托管枚举使用 `core.uix.enums_select`；工具本地选项使用普通控件。
- 优先 `.props()` 和 `.classes()`，复用 `app-*`、平台主题变量与语义色。
- Primary 用于主要动作，Secondary 用于持续选择和关系，语义色用于状态。
- 避免原始十六进制色值、渐变、装饰大图标、发光和大阴影。
- 自定义 CSS 限于工具根命名空间；不全局覆盖 `.q-card`、`.q-btn` 或平台壳。

## 交互与可访问性

- 根据业务表达初始、加载、空、成功、失败状态；失败保留输入并提供恢复动作。
- 查询提交条件与编辑中条件分离；分页沿用已提交条件。
- 长任务显示真实进度或不确定进度，不伪造百分比。
- 小屏允许筛选区换行，宽表格允许横向滚动，详情按需改为单列。
- 控件提供可见标签和键盘焦点，状态不只靠颜色区分。
- 写入或危险业务动作显示具体对象与影响范围，并遵守用户授权。
