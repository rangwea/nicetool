    需要在 NiceTool 里配置模型吗？

    工具创建与修改由外部 AI 编程助手完成，例如安装了 NiceTool Skill 的 Codex。平台本身不要求配置模型密钥；数据会按照所用助手及模型的配置处理。

    演示是预置功能，还是 AI 创建的工具？

    订单工作台是为演示创建的 NiceTool 工具，使用固定的合成订单数据。你可以按自己的需求创建不同的工具，而不局限于这些界面。

    “发布部署”会替我部署整个平台吗？

    不会。这里的发布是把工具源码上传到已部署的 NiceTool 实例。平台可通过 Docker 或 Python + MySQL 自行部署，具体步骤见文档。

    适合让任何人上传代码吗？

    工具代码在服务进程内执行。请将发布权限授予可信创作者，并根据数据敏感度配置认证、项目授权和预览访问策略。
