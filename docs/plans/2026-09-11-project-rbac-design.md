# 用户项目授权设计

## 目标

管理员可查看并访问全部工具。其他用户由管理员直接授予项目访问权；获得项目
访问权后，可访问该项目下当前及未来发布的全部工具。

## 数据模型

用户角色继续保存在 `auth_users.role`，仅用于区分管理员和普通用户。新增
`auth_user_resources`，使用 `user_id + resource_type + resource_name` 唯一标识
一项用户授权；项目权限的 `resource_type` 固定为 `project`。该表不使用数据库
外键。

## 权限规则

- 认证未启用时允许访问全部项目，保持本地开发行为。
- 管理员自动拥有全部项目权限，无需配置角色。
- 普通用户根据自身用户 ID 获得授权项目。
- 用户没有项目授权时看不到任何工具。
- 工具中心过滤未授权项目；直接访问工具 URL 时再次校验并返回 403。
- 新项目默认仅管理员可见，给角色授权后自动包含该项目下全部工具。

## 管理界面

用户管理页面增加“项目授权”操作，为普通用户勾选可访问项目。项目列表来自
当前工具目录，保存时整体替换该用户的项目授权。

## 验证

覆盖管理员旁路、普通用户直接授权、空授权拒绝、工具列表过滤和直接 URL 权限
判断；初始化 SQL 必须包含 `auth_user_resources`。
