# NiceTool skill 优化

用户已确认七项优化：安装路径、授权继承、渐进加载、查询快照、数据源参考、静态校验和行为验证。

保持 CLI/API 协议及工具单文件约定，使用实际加载的 skill 目录定位脚本，不改变用户工作目录。
明确沿用会话已有的目标/环境授权，只有歧义或授权范围变化才澄清。
把视觉文档分为基线、场景、复杂细节；只改逻辑时不强制加载视觉文档。
查询分页使用提交时的筛选快照，重置只修改待提交输入。
增加数据源参考和无执行副作用的 AST 校验脚本，区分静态检查、预览创建与实际交互验证。
用回归测试覆盖分页快照、补查、失败恢复、用户隔离、静态校验及任意安装位置的 CLI 调用。
保留用户已有的 `.agents/skills/nicetool` 删除状态，测试引用插件分发源。
