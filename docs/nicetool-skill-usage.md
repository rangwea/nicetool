# 开发任务示例

[返回文档索引](README.md)

先完成[Skill 安装和实例连接](nicetool-skill.md)，再向开发助手说明数据源、输入条件、结果字段和操作范围。以下项目名均为示例。

## 查询工具

> 在 demo 项目创建订单查询工具。按订单号和日期筛选，使用已登记的数据源，分页显示结果。先生成本地文件，不发布。

## 修改工具

> 读取 demo/order_query 当前源码，增加状态筛选。复用已有枚举，保留分页。修改后预览并检查日志。

## 预览排错

> demo/order_query 的预览页面报错。读取对应预览日志，定位原因，修复后重新预览。

## 发布

> 将已验证的本地 tools/demo/order_query.py 发布到指定实例的 demo/order_query，并核对正式状态。

发布前明确实例地址或命名环境。使用普通用户账号时，先确认具备发布权限。

## 分析面板

> 使用 NiceTool Skill 创建月度订单数量和金额趋势面板，支持日期范围、分页明细和有数量上限的 Excel 导出。

只读分析与业务写操作均使用 NiceTool Skill。写操作需要明确字段校验、确认交互、事务和失败处理。
