# 用户与管理员指南

[返回文档索引](README.md)

## 首次登录

启用 `AUTH_ENABLED=true` 后，访问 `/auth/login`。没有本地密码账号时，页面提供管理员初始化；初始化完成后，其他本地账号由管理员创建。使用临时密码登录的用户需要先修改密码。

## 使用工具

在 `/user` 按项目、标签或关键词查找工具。普通用户只能看到获授权的项目；管理员不受项目范围限制。点击工具进入 `/user/tools/{project}/{name}`。

看不到工具时，先确认工具已发布，再请管理员检查你的项目授权。预览成功不代表已经发布。

## 管理后台

`/admin` 提供以下入口：

| 入口 | 用途 |
| --- | --- |
| 用户管理 | 创建账号、禁用账号、重置密码和分配项目访问权限 |
| 工具管理 | 查看工具、源码及版本，执行有权限的管理操作 |
| 数据源管理 | 配置 MySQL/MongoDB 连接并测试连接 |
| 枚举管理 | 管理供工具使用的枚举 |
| 变量管理 | 配置工具读取的字符串 Key-Value |
| NiceTool 环境管理 | 为 CLI/安装脚本登记实例 URL、Token 环境变量名和默认环境 |
| 预览日志 | 查看预览列表及运行日志 |

环境管理不创建 Server 实例，也不修改服务的 `.env`。要生成客户端初始化配置，需要至少一个启用环境，并指定一个默认环境。

## 发布流程

开发者先在本地编写工具，通过预览验证，再由有权限的账号正式发布。数据库保存发布版本，工具中心使用正式版本。项目授权决定普通用户能访问哪些项目，不赋予发布、删除或回滚权限。

## Token

右上角用户菜单提供个人 Token 管理。完整 Token 只显示一次，丢失后重新生成；不再使用时撤销。配置方法见[Token 指南](nicetool-token-setup.md)。

## 常见问题

- **401**：浏览器会话或 CLI Token 无效、过期，重新登录或生成 Token。
- **403**：检查账号是否禁用、是否需要修改临时密码，以及项目授权和操作权限。
- **工具缺少入口**：工具必须定义顶层同步或异步 `main()`。
- **数据源连接失败**：从服务所在主机或容器检查地址、网络和数据库权限。
- **安装脚本返回 503**：检查后台是否配置了启用的默认环境，Skill 分发文件是否完整。

管理员可结合 `logs/app.log`、`logs/error.log`、`logs/tools/{project}/{tool}/tool.log` 和预览日志定位问题。分享日志前移除凭据与业务数据。
