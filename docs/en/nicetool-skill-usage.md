# Development Task Examples

These examples show how to ask an AI agent to create NiceTool tools.

## Query tool

```text
Create a NiceTool tool that queries order data by customer, status, and date range. Show paginated results and support CSV export.
```

## Dashboard

```text
Create a read-only sales dashboard with total revenue, order count, completion rate, monthly trend, and customer ranking.
```

## Form calculator

```text
Create a quote calculator. Users enter quantity, unit price, discount, tax, and service fee. Show subtotal, discount, tax, fee, and final total.
```

## Admin helper

```text
Create a safe admin helper that reads platform variables and displays validation results. Do not write any business data.
```

## Good request style

Include the business goal, required inputs, expected output, data source, safety constraints, and export needs. If the tool must use existing project models or APIs, mention the relevant module or endpoint.
